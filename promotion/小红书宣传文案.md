做外贸/跨境电商的姐妹应该都懂这个痛🥲

客户消息一条条丢过来，复制 → 切到翻译软件 → 翻译完 → 再切回WhatsApp回复 → 又要翻译一遍回复内容……一天下来光"切来切去"就耗掉半小时，忙起来还容易漏看消息、回错话。

我自己做了一个 WhatsApp Web 翻译插件，终于不用再来回切了👇

✅ 对方发消息，自动显示中文翻译在原文下方
✅ 你回复消息，输入框下方自动出现译文建议，一键复制粘贴发送
✅ 支持 DeepL 和 Google 两个翻译引擎，自己选
✅ 不会代替你自动发消息——译文只是建议，发送按钮你自己点，安全可控

重点来了：这个项目已经**完全开源**了❗

🔗 GitHub 地址：<https://github.com/Yanxuan-cloud/whatsapp-translator>
📝 MIT 协议，可以自由使用、修改、分享
💻 只需要 Chrome 浏览器，按教程几分钟装好

需要的配置：

- DeepL 免费版 Key（注册就送每月50万字符免费额度，不用绑卡）

- 或 Google Translate Key（需要绑卡但新号有$300试用额度）

⚠️ 说句实话：这是非官方第三方工具，跟 WhatsApp/Meta 官方没关系。使用任何第三方工具都有被风控的可能，插件第一次用会弹窗提醒风险，请自行判断是否使用。插件不会自动发消息，只做翻译显示和建议，已经把风险降到最低了。

装的时候需要手动加载（不是商店直接装），项目里有图文教程，跟着点几下就行，不需要会代码～

## 版本 B：开源分享型（适合技术社区/开发者圈子）

### 封面文字

我开源了一个 WhatsApp 翻译插件

### 正文

折腾了一个月，终于把 WhatsApp Web 双语翻译插件开源了🎉

起因是自己做外贸，每天和海外客户聊 WhatsApp，来回切翻译软件太痛苦了。搜了一圈没找到好用的免费方案，干脆自己写了一个，现在分享出来。

技术栈很简单：Chrome Extension + Manifest V3 + 原生 JS，没有框架依赖，代码量不大但该有的都有👇

🔧 功能：

- 收到消息自动翻译显示在原文下方

- 发消息时给出译文建议 + 一键复制（不会自动发送！这是设计原则）

- DeepL / Google Translate 双引擎可切换

- 按联系人记忆语言，不用每次手动选

- 本地额度统计，防止 API 超额扣费

- 深色模式适配

🔐 安全设计：

- 权限最小化，只申请 storage 权限 + 三个域名

- 不经过任何中间服务器，翻译请求直接发给你配置的 API

- API Key 存在本地 chrome.storage，不上传

- 首次使用强制弹窗风险告知，用户同意后才启动

- innerHTML 全部替换为安全 DOM API（防 XSS）

- Google API Key 用请求头传递，不暴露在 URL 中

🔗 仓库地址：<https://github.com/Yanxuan-cloud/whatsapp-translator>
📜 MIT 协议，欢迎 Star / Fork / PR

后续想加：群聊按发言人翻译、更多引擎（DeepSeek/豆包）、翻译结果持久化缓存。

如果是做外贸/跨境电商的朋友，直接用就行，README 里有安装教程和 API Key 申请指南。如果是开发者，欢迎来提 PR 一起完善～
